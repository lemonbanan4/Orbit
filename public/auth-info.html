This dedicated endpoint provides complete transparency regarding how the Orbit mobile application connects to and utilizes user data retrieved via Google APIs.

1. Exactly How Orbit Uses Google Sign-In

Orbit is a premium mobile habit tracking system. We utilize Google OAuth 2.0 Secure Sign-In solely to authenticate users and register cloud profiles. This integration maps user accounts across multiple personal devices to ensure cross-device data continuity for habit constellations, completion histories, and daily streaks.

2. Specific API Scope Justification

Our application integrates the Gmail API Core Scope (https://mail.google.com/) via secure backend Firebase extension pipelines. This scope is used strictly to transmit automated, user-configured email reminder packets and daily milestone recap diagnostics to the user's personal verified Gmail inbox. Orbit does not read, parse, scrape, store, or transmit your incoming emails or pass any data profiles to external marketing networks.

3. Data Access and Revocation Controls

Users maintain full sovereignty over their private records. You can completely revoke Orbit's access to your Google Account at any time via your official Google Account Security Settings hub. Furthermore, users can request a clean slate wipe and permanent account erasure directly inside the application settings dashboard or by emailing our direct operational helpdesk lines at contact@orbitroutine.com.
